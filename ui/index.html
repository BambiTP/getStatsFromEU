TagPro CTF Stats

CTF stats for tagpro.eu matches, worked out the same way as the TagPro League.

1. Where the matches come from

A match that is in more than one of the files is only counted once.

Downloads the matches in big pieces (fast) and keeps them in the app's "cache" folder for next time.

One request every 2 seconds, so best for a few hundred matches at most. Downloaded matches are kept in the "cache" folder.

2. Which matches
from to
No filters: every row is kept.
Filters

Keep only the rows you want. Inside a box, every condition has to be true (and). A row is kept if any box is true (or). For lists of names, separate them with commas. Filters match names exactly; a name that is in "Combine names" below gets a Combine? button that adds that player's other names (× hides it).

As text

One condition per line, like time_limit = 8; a line saying or starts the next box. The same text works with the command line's --filter.

One player per line. Any of these work: NewName: OldName, SmurfName or OldName, SmurfName -> NewName or NewName, OldName, SmurfName (the first name is the one used in the stats). If a name is already in the list, the other names are added to that player.
